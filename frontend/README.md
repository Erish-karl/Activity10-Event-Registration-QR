# Activity 10 – Event Registration & Ticket QR Scanner

## Description
A web-based platform where organizers create events and attendees register online.
Each registration generates a unique QR code ticket that is scanned for entry verification.

## Tech Stack
- Frontend: ReactJS
- Backend: Node.js, NestJS, TypeScript
- Database: MongoDB / MySQL
- QR Code: UUID + QR Code Generator
- API Docs: Swagger

## Roles
- Admin
- Organizer
- Attendee
